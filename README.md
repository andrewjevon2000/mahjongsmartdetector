# Sempoa Mahjong · Smart Detector

A Hong Kong mahjong assistant (Majé House Rules) for your phone. Everything runs in the browser:

- **Live camera** — a tile detector (YOLO11n, ONNX) runs on the phone via onnxruntime-web; your hand is saved automatically as soon as 13/14 tiles are read.
- **Winning chances** — every reachable winning combination with its probability, points and distance, plus the next move (what to discard, when to Pong/Chi/Kong/HU) toward a valid win (minimum 3 points).
- **Opponent reading** — how likely each opponent is ready, the pattern they seem to chase (Half/Full Flush, Dragon, Wind, All Pongs), the risk of each discard, and an Attack / Careful / Defend mode.

Open: `https://andrewjevon2000.github.io/mahjongsmartdetector/`

## Layout

| Path | Contents |
|---|---|
| `index.html` | The built app (generated by `build.py`) |
| `src/engine.js` | Engine: shanten, pattern routes, Majé scoring, simulation, opponent reading |
| `src/app.js`, `src/app.html` | UI (one main screen + on-demand full-screen views) |
| `src/live.js` | Live camera + tile detection |
| `model/` | `mahjong.onnx` + `meta.json` (output of `tools/train.py`) |
| `test/engine.test.js` | Engine tests (`node test/engine.test.js`) |
| `tools/publish.sh` | Build, test, commit, push and enable GitHub Pages |

## Current model

YOLO11n, 512 px, 30 epochs on an Apple M1 (dataset v83: 6,294 train / 788 val / 568 test).

| | mAP50 | mAP50-95 |
|---|---|---|
| Validation | 87.0% | 66.4% |
| Test | 84.4% | 65.3% |

Regular tiles (Characters/Dots/Bamboo/Winds/Dragons) are mostly 80–97%. The weakest classes are
Flower/Season tiles (39–70%) and 9 Characters (74%). If tiles from your own set are often misread,
collect photos with **Save training photo**, label them, merge them into the dataset and retrain.

## Retraining the model

```bash
python3 tools/train.py ~/Downloads/<roboflow-yolo-dataset>.zip 30 512
python3 build.py
```
